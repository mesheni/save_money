# SaveMoney

Офлайновый трекер личных финансов для Android (Russian-first UI). Ввод расхода за
2 касания — с главного экрана или с виджета, без сети и без аккаунтов: база SQLite
лежит только на устройстве, экспорт — CSV в любой момент.

## Возможности (MVP 1.0)

- **Быстрый ввод**: расход / доход / перевод, кастомная клавиатура, угадывание
  категории по магазину; опция «сохранять сразу при выборе категории» (2 касания).
- **Android-виджет 4×1**: пресеты «＋100 / ＋500 / ＋1000 / ✎» — тап открывает ввод
  с предзаполненной суммой.
- **Счета** (наличные / карта / банк) с начальными остатками, архивом и переводами.
- **Категории**: корень + подкатегория, ~65 дефолтных RU-категорий, свои иконки.
- **Долги** в обе стороны («мне должны» / «я должен») с платежами и автозакрытием.
- **Регулярные платежи**: ежемесячно / еженедельно / каждые N дней, автосоздание
  транзакций при запуске и возврате в приложение.
- **Бюджеты** по категориям или общий, план/факт за цикл.
- **«До зарплаты»**: хватит ли денег, «₽ в день», сменный цикл (якорь + длина).
- **Отчёты**: произвольный период, круговая и столбчатая диаграммы, топ категорий.
- **Экспорт CSV** (UTF-8 BOM, `;`, русская локаль Excel), резервная копия базы.
- **Тема**: системная / светлая / тёмная, дизайн-система «Vibrant» (`design_vibrant/`).

## Стек

- .NET 10 + .NET MAUI (SingleProject: android / windows в CI, iOS-head в проекте)
- SQLite через sqlite-net-pcl, миграции через `PRAGMA user_version`
- CommunityToolkit.Mvvm, LiveCharts2 (SkiaSharp)
- xUnit: 58 тестов на слой `SaveMoney.Core`

## Структура

```
src/
  SaveMoney.Core/        модели, репозитории, сервисы, миграции (без UI)
  SaveMoney/             MAUI-приложение: XAML, ViewModels, Android-платформа
  SaveMoney.Tests/       xunit-тесты Core
DEVPLAN.md               план разработки: фазы, статусы, отложенное
UIPLAN.md                карта навигации, макеты экранов, функции по версиям
```

## Сборка и тесты

```bash
dotnet test src/SaveMoney.Tests/SaveMoney.Tests.csproj

# Android (нужен workload maui-android)
dotnet build src/SaveMoney/SaveMoney.csproj -f net10.0-android -c Release

# Windows (нужен workload maui-windows)
dotnet build src/SaveMoney/SaveMoney.csproj -f net10.0-windows10.0.19041.0 -c Release
```

CI (`.github/workflows/ci.yml`) гоняет тесты и обе сборки на каждый push в `master`.
