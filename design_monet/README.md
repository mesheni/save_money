# Monet

Откройте [index.html](index.html): статические образцы ввода, истории, отчётов и формы в обеих темах. Цвета соответствуют встроенной абрикосовой схеме `MonetScheme`. Макеты показывают визуальный язык; компоновка работающего MAUI-приложения адаптируется к размеру экрана и системному шрифту. Данные на макетах иллюстративные. Старые `design_vibrant` оставлены как архив.
